## 1. 目标

让读者在一份报告里看清三件事，并且每个结论都能追到证据文件：

1. 系统完成了什么；
2. 是怎么完成的；
3. 如何证明完成得好。

管理者只读第 0 层摘要页即可得出结论；技术读者可以逐层展开到证据文件。

## 2. 约束

- **存放位置**：报告、本设计说明、报告引用的截图都在 `docs/verification/` 下。该目录被候选快照排除，所以写入报告不会改变候选 ID，也不会让评审或验收结论失效。不得写入 `docs/design/**` 或任何其他快照范围内的路径。
- **完全离线**：单个 HTML 文件，不加载任何外部脚本、字体、样式或图片（不用 Mermaid、CDN）。图用内联 SVG 或纯 HTML/CSS 绘制。
- **不新增依赖**：不写生成脚本，不安装任何包。
- **不含凭据**：只展示 README 已公开的开发演示账号；不出现 Session、Token、Cookie 值。
- **截图**：从验收截图中选 8 张，以 base64 内嵌（合计原图约 714 KB，内嵌后约 0.95 MB）：
  `ui-11-dashboard`、`ui-08-circulation-borrow`、`ui-08b-circulation-renew`、`ui-08d-circulation-error`、`ui-04-reader-home`、`ui-06-reader2-loans-overdue`、`ui-05-reader-403`、`ui-10-overdue-report`（均在 `acceptance/screenshots/`）。其余截图在证据索引里以相对路径链接。
